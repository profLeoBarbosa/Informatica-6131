Revisão da Web e Introdução à Inteligência Artificial

Revisão da Web

A Internet é uma rede mundial de computadores conectados entre si. Ela permite acessar informações, utilizar serviços e se comunicar com pessoas do mundo inteiro.

  • Acessar sites
  • Enviar e receber e-mails
  • Assistir vídeos
  • Fazer compras
  • Estudar e trabalhar
Navegador: é o programa usado para acessar páginas da Internet. Exemplos: Google Chrome, Microsoft Edge, Mozilla Firefox, Opera e Safari.

URL é o endereço de uma página na Internet, como https://www.gov.br.

Os mecanismos de busca, como Google e Bing, ajudam a localizar informações. Quanto mais específica for sua pesquisa, melhores costumam ser os resultados.

Navegue com segurança:
  • Verifique o endereço do site.
  • Desconfie de promoções exageradas.
  • Não informe senhas em sites desconhecidos.
  • Evite clicar em links suspeitos.
  • Confirme informações em fontes confiáveis.

O que é Inteligência Artificial?

A Inteligência Artificial (IA) é um conjunto de tecnologias que permite aos computadores realizar tarefas que normalmente exigiriam inteligência humana.

  • Responder perguntas
  • Traduzir textos
  • Criar textos e imagens
  • Reconhecer voz
  • Analisar informações

A IA não possui consciência nem sentimentos. Ela utiliza modelos matemáticos treinados com grandes volumes de dados.

Onde encontramos IA?

  • ChatGPT
  • Gemini
  • Microsoft Copilot
  • Siri
  • Alexa
  • Google Tradutor
  • Netflix
  • Spotify
  • YouTube

Como a IA funciona?

Ela analisa dados, identifica padrões e gera respostas com base em seu treinamento. A IA calcula probabilidades para produzir a resposta mais adequada, podendo cometer erros.

Prompt

Prompt é o comando enviado para uma IA.

Exemplo:

Ruim: Computador

Bom: Explique o que é um computador utilizando uma linguagem simples para um aluno iniciante.

Boas práticas

  • Faça perguntas claras.
  • Dê contexto.
  • Revise as respostas.
  • Confira informações importantes.
  • Não compartilhe dados pessoais.
